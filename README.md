# Каретка

[Открыть письменный стол](https://karetka.netlify.app/) · [Как хранить черновики](https://karetka.netlify.app/drafts.html) · [Свой домен, сервер, оплата и резервные копии](docs/HOSTING.md)

«Каретка» — редактор для книг и рассказов на компьютере, планшете с клавиатурой и телефоне. Начните с «Рукописи → Новая рукопись» и выберите один текст, главы или сцены. На письменном столе можно попробовать машинку на демонстрационном письме.

## Письменный стол

- В режиме «Машинка» каретка движется за последней буквой. Текст дописывается в конец. В настройках можно разрешить Backspace. Для выделения, перестановки абзацев и обычной работы с курсором включите «Правка».
- При переносе строки вал подаёт непрерывный лист вместе с оттиском и волокнами. Ручка справа прокручивает текст по строкам. Тяните её вверх или вниз мышью или пальцем. Когда ручка в фокусе, работают стрелки, Page Up и Page Down. Enter возвращает к набору.
- В «Фокусе» панели скрываются, поля подстраиваются под экран. Чтобы выйти, коснитесь каретки или нажмите Esc.
- Днём лист освещён равномерно. Ночью за кареткой следует свет лампы. Оттенок бумаги и цвет чернил задаются отдельно от освещения. В настройках доступны четыре [локальных кириллических шрифта](dist/fonts/CREDITS.md), фактура и громкость клавиш.
- В «Помощниках» ведите карточки персонажей, мест и деталей мира, составляйте план главы и находите повторы и длинные предложения. Нажмите счётчик знаков, чтобы задать цель для текущего раздела.

## Хранение рукописей

| Где хранить | Как пользоваться |
| --- | --- |
| На устройстве | Можно писать без аккаунта. Откройте приложение один раз онлайн и дождитесь готовности офлайн-режима. Черновики привязаны к этому браузеру и адресу сайта. Перед очисткой данных сохраните файл. |
| В личном облаке «Каретки» | Войдите в кабинет и выберите «Включить зашифрованное облако» на устройствах, которые хотите связать. При первом входе сохраните резервный код. Текст, заголовки, план и карточки шифруются перед отправкой. Изменения после работы офлайн отправляются при возвращении сети, пока приложение открыто, либо при следующем запуске. |
| В своей папке, iCloud Drive или Google Диске | В кабинете выберите «Мой защищённый файл». Задайте отдельный пароль и сохраните файл .karetka в нужную папку через системное меню. Это копия на момент экспорта. Для восстановления откройте её с тем же паролем. |
| В Google Документах или Word | Экспортируйте DOCX и откройте его в выбранном редакторе. Это отдельная редактируемая копия с читаемым текстом. Для полного переноса с планом и картотекой подходят .karetka и JSON. JSON также содержит читаемый текст. |

При первой регистрации гостевые рукописи остаются на устройстве. В кабинете кнопка «Перенести рукопись с этого устройства» создаёт отдельную копию выбранной книги. Если два устройства параллельно меняли одну рукопись, редактор сохраняет обе редакции. Контрольные версии можно делать из кабинета и восстанавливать отдельной копией.

Старый код синхронизации по-прежнему открывает прежнее хранилище в настройках. Если черновики остались на [старом адресе](https://karetka-alchemist308.netlify.app/), откройте его в том же браузере и перенесите книгу с помощью файла. Личные рукописи и аварийные копии профиля шифруются и в браузере. Пока профиль открыт, редактор может читать книги, в том числе офлайн. На общем устройстве выйдите из кабинета после работы. Гостевые черновики хранятся в обычном хранилище браузера. Храните резервный код аккаунта и пароль экспортированного файла в менеджере паролей.

## Тарифы

| Возможность | Черновик | Автор | Мастерская |
| --- | ---: | ---: | ---: |
| Локальные рукописи | Без лимита | Без лимита | Без лимита |
| Машинка, помощники, шрифты и экспорт | Да | Да | Да |
| Рукописи в личном облаке | 1 | 20 | 100 |
| Контрольные версии на рукопись | 0 | 5 | 25 |
| Доступ на 30 дней | Бесплатно | 299 ₽ | 599 ₽ |
| Доступ на 365 дней | Бесплатно | 2 990 ₽ | 5 990 ₽ |

«Автор» можно попробовать один раз на 14 дней без карты. Каждый платный период автор продлевает вручную. После окончания срока прежние книги и версии доступны для чтения и экспорта. У владельца постоянный доступ ко всем функциям и управлению тарифами пользователей. Порядок первого входа владельца и подключения магазина ЮKassa приведён в [инструкции по размещению](docs/HOSTING.md).

## Локальный запуск

Требуется Node.js 22.13 или новее. Сборка проверяется на Node.js 24.

```sh
npm ci
npm test
npm run dev
```

Откройте адрес, выведенный сервером. Локальная база SQLite создаётся в каталоге var. Для самостоятельного хостинга в проекте есть Docker Compose, Caddy с HTTPS и команды резервного копирования. На Netlify та же серверная логика использует приватные хранилища Netlify Blobs.
