# Каретка

[Открыть приложение](https://karetka-alchemist308.netlify.app/)

Редактор прозы для компьютера, планшета с клавиатурой и телефона. Бумага неподвижна по горизонтали. Каретка и свет следуют за курсором, а при переходе на новую строку каретка возвращается к полю.

## Первое открытие

Откройте «Рукописи» и нажмите «Новая рукопись». Выберите единый текст, главы или сцены. На письменном столе также есть небольшая демонстрационная рукопись. При первом изменении приложение создаёт вашу собственную копию.

- В «Оглавлении» добавляйте главы и сцены, меняйте их порядок и названия.
- В «Настройках» выберите свободные исправления или дописывание черновика в конец. «Правка» всегда открывает обычный текстовый редактор.
- Включите «Фокус», чтобы оставить на экране бумагу и каретку. Для выхода нажмите кнопку в правом верхнем углу или Escape.
- «Помощники» содержат картотеку персонажей, мест и деталей мира, план для каждого раздела и вычитку с переходом к повторам и длинным предложениям.
- «Экспорт» сохраняет весь текст в DOCX или TXT. Копия JSON также включает картотеку, планы и структуру. Чтобы открыть копию, выберите «Рукописи» → «Открыть из файла».

## Офлайн и синхронизация

1. Один раз откройте приложение по HTTPS на каждом устройстве. В настройках появится сообщение «Офлайн-режим готов на этом устройстве».
2. На первом устройстве выберите «Настройки» → «Синхронизация устройств» → «Создать хранилище». Сохраните код подключения. Он нужен для доступа к рукописям с нового устройства.
3. На остальных устройствах откройте тот же адрес и введите код в разделе синхронизации.
4. Во время работы текст сохраняется в браузере. При появлении связи открытое приложение отправляет изменения и загружает новые версии. Если приложение было закрыто, обмен продолжится при следующем открытии. Строка состояния различает локальное и сетевое сохранение.

Код создаётся на первом устройстве из 192 случайных бит. Клиент выводит отдельный токен доступа и ключ шифрования. Перед отправкой содержимое, включая заголовки и карточки, шифруется с помощью AES-GCM. Код доступа хранится на подключённых устройствах. Резервная копия JSON содержит читаемый текст и пригодна для переноса независимо от кода. При параллельном редактировании одной рукописи приложение оставляет обе редакции в списке. Сопоставить и объединить их можно в режиме правки.

## Размещение на Netlify

Импортируйте этот GitHub-репозиторий в Netlify. Ветка публикации — `main`. Команда сборки `npm test`, каталог сайта `dist`, каталог функций `netlify/functions`. Параметры заданы в `netlify.toml`. Функция использует хранилище Netlify Blobs текущего сайта. Токены GitHub, ключи API и рукописи в репозитории не требуются.

## Локальный запуск и проверка

Требуется Node.js 22 или новее.

```sh
npm ci
npm test
npx netlify-cli dev
```

Для проверки интерфейса без облачной функции достаточно раздать каталог `dist` локальным HTTP-сервером. Офлайн-кэш доступен на localhost и HTTPS. Тесты покрывают структуру рукописи и экспорт, доступность файлов офлайн-версии, обмен между двумя независимыми клиентами, восстановление после разрыва передачи и параллельные правки.
